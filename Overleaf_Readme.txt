HoneyBee Shop user manual: Overleaf and screenshot notes

1. Create a new blank project in Overleaf.
2. Upload HoneyBee_User_Documentation.tex.
3. Create a folder named screenshots and add any screenshots using the exact filenames listed below. The LaTeX file compiles without screenshots and displays a labeled placeholder for each missing image.
4. In Overleaf, set the main document to HoneyBee_User_Documentation.tex. The default pdfLaTeX compiler is suitable.
5. Select Recompile, review each page, and download the PDF. Recompile after replacing any screenshot.
