1\n---PAGE 4---\nIntroduction
The City Centre of Media Institute Management System is a modern digital platform created
to make day-to-day activities in an educational institute easier, faster, and more organized.
Instead of relying on paper files or manual work, the system brings all important tasks—such
as managing students, teachers, courses, attendance, fees, and exams—into one place. It is
designed to be simple to use, so anyone in the institute can access the information they need
without confusion.
This system provides separate, easy-to-navigate panels for administrators, teachers, and
students. Administrators can manage the entire institution, teachers can handle their classes
and student performance, and students can view their timetable, results, fees, and
announcements. The platform also works smoothly on computers and mobile devices, making
it convenient to use anywhere, anytime.
Overall, the Institute Management System helps improve communication, reduces paperwork,
saves time, and ensures that important information is always up-to-date. It provides a complete
digital experience that supports smooth academic and administrative operations within the City
Centre of Media.

36\n---PAGE 39---\nTroubleshooting and FAQs
Common Issues & Solutions
1. Unable to Login
Possible Causes:
➢ Incorrect username or password
➢ Account not activated
➢ Internet connection issues
Troubleshooting Steps:
➢ Verify username and password
➢ Check for stable internet connectivity
➢ If the problem continues, contact the system administrator.
2. Dashboard or Pages Not Loading
Possible Causes:
➢ Slow internet connection
➢ Browser cache causing conflicts
➢ Server temporarily busy
Troubleshooting Steps:
➢ Refresh the page or try again after a few minutes.
➢ Clear browser cache/cookies and reload the system
➢ Make sure stable internet connection
3. System Logging Out Automatically
Possible Causes:
➢ Inactive session timeout for security
Troubleshooting Steps:
➢ Regularly save work while using the system.
➢ Log in again if the session expires.
4. Data Not Saving After Submission
Possible Causes:
➢ Required fields not filled
➢ Session timeout
➢ Poor internet connectivity
Troubleshooting Steps
➢ Re-submit after confirming internet status.
➢ Log out and log back into the system
37\n---PAGE 40---\nFAQs
Q1: Who can access the system?
The system can be accessed by Admin, Teachers, and Students. Each role has different
permissions.
Q2: Can I update my profile?
No. Only admin can update the profile
Q3: What browsers does the system support?
Google Chrome, Firefox, Microsoft Edge, and other modern browsers.
Q4: Can the admin add new teachers and students?
Yes, the admin has full control to create, edit, and remove user accounts.
Q5: Can I use the system without internet?
No. The system requires an active internet connection to function.
